# Girls’ Empowerment for Community Development (GECOD)

A simple landing page for the fundraiser to build safe toilets for girls at Ayivu in Bidibidi Refugee Settlement, Yumbe District, Uganda.

## Local preview

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Content

This page is designed to be easy to customize for GitHub Pages or any static hosting service.

## Notes

- The website is static and does not process payments.
- Donations are directed to Airtel Money or bank transfer details shown on the page.
- Pledges are confirmed via WhatsApp.
